# Contributing

Use domain terms from `CONTEXT.md`. Test public behaviour through the
Manager/BDD API or CLI process seam. Do not expose private node IDs as a stable
contract or add unbounded operations.

Run every command in `docs/TESTING.md`. For future changes, the commit message,
pull-request description, or accompanying design document must explain the
algorithm, complexity, Resource Budget effect, tests, and provenance of fixtures
or prior art as applicable.
